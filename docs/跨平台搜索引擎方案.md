# 跨平台搜索引擎技术方案

## 项目目标

构建一个兼容 iOS 和 Android 的跨平台文档搜索引擎，支持中文分词和基本全文检索功能。

## 核心技术选型

### SQLite FTS5 + 外部中文分词器

**选择理由:**
- ✅ SQLite 是纯 C 实现，iOS/Android 原生支持
- ✅ FTS5 (Full-Text Search) 是成熟的全文检索方案
- ✅ 单文件集成，易于跨平台部署
- ✅ 无需从头实现倒排索引、排序算法等复杂功能

---

## 方案一: 应用层预处理 (推荐快速开发)

### 架构设计

```
┌─────────────┐
│  文档输入    │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 中文分词库   │  ← 使用现成的分词库
│ (jieba等)   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  分词结果    │
│ "word1 word2"│
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ SQLite FTS5 │  ← 自编译版本
│   索引引擎   │
└─────────────┘
```

### 实现步骤

#### 1. 自编译 SQLite (避免系统版本问题)

**为什么要自己编译:**
- iOS/Android 系统自带 SQLite 版本较旧
- 老版本可能不支持 FTS5
- 版本碎片化严重,行为不一致

**编译方法:**

```bash
# 1. 下载 SQLite Amalgamation
# 访问 https://www.sqlite.org/download.html
# 下载 sqlite-amalgamation-xxx.zip
# 解压得到: sqlite3.c 和 sqlite3.h (单文件!)

# 2. iOS 编译 (使用 Xcode)
# 创建 Static Library 项目
# 添加 sqlite3.c
# Build Settings 添加:
#   OTHER_CFLAGS = -DSQLITE_ENABLE_FTS5

# 3. Android 编译 (使用 NDK)
# CMakeLists.txt:
add_library(sqlite3 STATIC 
    src/main/cpp/sqlite3.c
)
target_compile_definitions(sqlite3 PRIVATE 
    SQLITE_ENABLE_FTS5
    SQLITE_ENABLE_JSON1
)
```

#### 2. 集成中文分词库

**iOS 选择:**
- [jieba-ios](https://github.com/yanyiwu/iosjieba) - C++ 实现
- [SwiftyJieba](https://github.com/jindulys/SwiftyJieba) - Swift 封装

**Android 选择:**
- [jieba-android](https://github.com/huaban/jieba-android) - Java 实现
- [HanLP](https://github.com/hankcs/HanLP) - 功能更强大

#### 3. 应用层实现

**iOS 示例 (Swift):**

```swift
import SQLite3

class SearchEngine {
    var db: OpaquePointer?
    
    func initialize() {
        // 使用自编译的 SQLite
        sqlite3_open(dbPath, &db)
        
        // 创建 FTS5 表
        let sql = """
        CREATE VIRTUAL TABLE IF NOT EXISTS documents 
        USING fts5(title, content, tokenize='unicode61');
        """
        sqlite3_exec(db, sql, nil, nil, nil)
    }
    
    func indexDocument(title: String, content: String) {
        // 1. 使用 jieba 分词
        let titleWords = Jieba.cut(title).joined(separator: " ")
        let contentWords = Jieba.cut(content).joined(separator: " ")
        
        // 2. 插入 FTS5 表
        let sql = "INSERT INTO documents VALUES (?, ?)"
        var stmt: OpaquePointer?
        sqlite3_prepare_v2(db, sql, -1, &stmt, nil)
        sqlite3_bind_text(stmt, 1, titleWords, -1, nil)
        sqlite3_bind_text(stmt, 2, contentWords, -1, nil)
        sqlite3_step(stmt)
        sqlite3_finalize(stmt)
    }
    
    func search(query: String) -> [SearchResult] {
        // 1. 分词查询
        let queryWords = Jieba.cut(query).joined(separator: " ")
        
        // 2. FTS5 查询
        let sql = """
        SELECT title, content, rank 
        FROM documents 
        WHERE documents MATCH ? 
        ORDER BY rank;
        """
        // 执行查询...
    }
}
```

**Android 示例 (Kotlin):**

```kotlin
class SearchEngine(context: Context) {
    private val db: SQLiteDatabase
    private val jieba = JiebaSegmenter()
    
    init {
        // 使用自编译的 SQLite
        db = SQLiteDatabase.openOrCreateDatabase(dbPath, null)
        
        // 创建 FTS5 表
        db.execSQL("""
            CREATE VIRTUAL TABLE IF NOT EXISTS documents 
            USING fts5(title, content, tokenize='unicode61')
        """)
    }
    
    fun indexDocument(title: String, content: String) {
        // 1. 分词
        val titleWords = jieba.process(title, JiebaSegmenter.SegMode.SEARCH)
            .joinToString(" ")
        val contentWords = jieba.process(content, JiebaSegmenter.SegMode.SEARCH)
            .joinToString(" ")
        
        // 2. 插入
        db.execSQL(
            "INSERT INTO documents VALUES (?, ?)",
            arrayOf(titleWords, contentWords)
        )
    }
    
    fun search(query: String): List<SearchResult> {
        val queryWords = jieba.process(query, JiebaSegmenter.SegMode.SEARCH)
            .joinToString(" ")
        
        return db.rawQuery(
            "SELECT * FROM documents WHERE documents MATCH ? ORDER BY rank",
            arrayOf(queryWords)
        ).use { cursor ->
            // 处理结果...
        }
    }
}
```

### 优点
- ✅ 实现简单,开发周期短 (1-2周)
- ✅ 使用成熟分词库,准确率高
- ✅ 易于调试和维护
- ✅ 分词算法可随时更换

### 缺点
- ⚠️ 分词和索引分离,性能略低
- ⚠️ 需要额外存储分词结果
- ⚠️ 无法利用 FTS5 的动态分词能力

## 方案二: SQLite Tokenizer 扩展 (专业方案)

### 架构设计

```
┌─────────────┐
│  文档输入    │
└──────┬──────┘
       │
       ▼
┌─────────────────────┐
│   SQLite FTS5       │
│                     │
│  ┌───────────────┐ │
│  │ Custom        │ │  ← C 实现的分词器
│  │ Tokenizer     │ │
│  │ (中文分词)     │ │
│  └───────────────┘ │
│                     │
│  自动分词 + 索引    │
└─────────────────────┘
```

### 实现步骤

#### 1. 实现 FTS5 Tokenizer 接口

**核心代码 (C):**

```c
#include "sqlite3.h"

// 分词器结构
typedef struct ChineseTokenizer {
    fts5_tokenizer base;
    // 分词词典数据
    TrieTree* dict;
} ChineseTokenizer;

// 分词函数
static int chineseTokenize(
    void *pCtx,
    int flags,
    const char *pText, int nText,
    int (*xToken)(void*, int, const char*, int, int, int)
) {
    ChineseTokenizer *p = (ChineseTokenizer*)pCtx;
    
    // 中文分词算法 (最大匹配/HMM)
    int pos = 0;
    while (pos < nText) {
        // 查找最长匹配词
        Word word = findLongestMatch(p->dict, pText + pos, nText - pos);
        
        // 回调通知 FTS5
        int rc = xToken(pCtx, 0, word.text, word.len, pos, pos + word.len);
        if (rc != SQLITE_OK) return rc;
        
        pos += word.len;
    }
    
    return SQLITE_OK;
}

// 注册 tokenizer
static int registerChineseTokenizer(sqlite3 *db) {
    fts5_api *pApi = NULL;
    sqlite3_stmt *pStmt = NULL;
    
    // 获取 FTS5 API
    sqlite3_prepare_v2(db, 
        "SELECT fts5(?)", -1, &pStmt, 0);
    sqlite3_bind_pointer(pStmt, 1, &pApi, "fts5_api_ptr", 0);
    sqlite3_step(pStmt);
    sqlite3_finalize(pStmt);
    
    // 注册分词器
    fts5_tokenizer tokenizer = {
        chineseCreate,
        chineseDelete,
        chineseTokenize
    };
    
    return pApi->xCreateTokenizer(pApi, 
        "chinese",
        &tokenizer,
        &tokenizer,
        NULL);
}
```

#### 2. 分词算法实现

**可选方案:**

**A. 集成现有 C 分词库:**
```c
// 使用 cjieba
#include "cjieba/Jieba.h"

Jieba jieba = NewJieba(DICT_PATH, HMM_PATH);
CJiebaWord* words = Cut(jieba, text);
// 遍历 words 调用 xToken
```

**B. 自己实现简单分词:**
```c
// 基于词典的最大匹配
typedef struct TrieNode {
    char16_t ch;
    bool isWord;
    struct TrieNode* children[MAX_CHILDREN];
} TrieNode;

// 最大正向匹配
Word maxForwardMatch(TrieNode* root, const char* text, int len) {
    int maxLen = 0;
    int matched = 0;
    
    TrieNode* node = root;
    for (int i = 0; i < len; i++) {
        node = trieFind(node, text[i]);
        if (!node) break;
        
        matched++;
        if (node->isWord) {
            maxLen = matched;
        }
    }
    
    return (Word){text, maxLen > 0 ? maxLen : 1};
}
```

#### 4. 使用方式

```sql
-- 创建使用中文分词的表
CREATE VIRTUAL TABLE documents 
USING fts5(title, content, tokenize='chinese');

-- 直接插入原文 (自动分词)
INSERT INTO documents VALUES ('红烧肉的做法', '将猪肉切块,焯水后...');

-- 查询 (自动分词)
SELECT * FROM documents WHERE documents MATCH '红烧肉';
```

### 优点
- ✅ 性能最优,分词在 C 层完成
- ✅ 使用透明,应用层无需关心分词
- ✅ FTS5 原生支持,功能完整
- ✅ 索引更新自动触发分词

### 缺点
- ⚠️ 开发难度高 (需要 C 编程经验)
- ⚠️ 调试困难
- ⚠️ 词典更新需要重新编译
- ⚠️ 开发周期长 (3-4周)

**加载词典:**
```c
TrieNode* loadDict(const char* dictPath) {
    FILE* f = fopen(dictPath, "r");
    TrieNode* root = createTrieNode();
    
    char word[256];
    int freq;
    while (fscanf(f, "%s %d", word, &freq) == 2) {
        trieInsert(root, word, freq);
    }
    
    fclose(f);
    return root;
}
```
